# McRuff Implementation Plan

> Execution: native implementation in this session, consistent with the user's delegation of all choices.

**Goal:** A complete browser-playable Doom-style canine action game.
**Architecture:** Pure simulation consumed by a Canvas renderer and DOM interface. Web Audio synthesizes all game sound.
**Tech stack:** Native JavaScript modules, HTML, CSS, Node built-in test runner and static server.
**Spec:** docs/superpowers/specs/2026-10-10-mcruff-design.md

## Constraints
- No runtime dependencies, no external asset fetches during play.
- Three playable districts, bite and stun-bark combat, pickups, boss and ending.
- Keyboard-only and touch fallback; pause on lost focus; audio starts from user input.

## Review focus
- Collision and combat cannot pass through walls.
- Every spawn, pickup and exit is reachable.
- Restart discards stale movement, timers and previous campaign state.
- Unavailable pointer lock, audio or storage must not prevent playing.
- Responsive menus and touch controls must remain usable.
